# AGENTS.md — Regras de Desenvolvimento do Portfólio

Este documento estabelece as diretrizes e regras para o desenvolvimento do portfólio pessoal de **Davi Kusumi**.

## Regras Obrigatórias
1. **Stack Tecnológica**:
   - Exclusivamente **HTML5**, **CSS3** e **JavaScript puro (Vanilla JS)**.
   - Proibido o uso de frameworks ou bibliotecas pesadas externas (sem React, Vue, Tailwind, Bootstrap, etc.).
2. **Estrutura de Arquivos**:
   - `index.html`: Marcação semântica com seções devidamente nomeadas.
   - `style.css`: Estilização completa, variáveis de design e animações.
   - `script.js`: Toda a lógica de partículas, interações do cursor, 3D e eventos.
3. **Identidade e Referências**:
   - Antes de criar ou alterar qualquer arquivo, consultar obrigatoriamente:
     - `identidade.md`
     - `referencias.md`
     - `funcionalidades.md`
   - Nada de layouts genéricos de templates: seguir a identidade visual autoral e referências solicitadas.
4. **Desenvolvimento Gradual**:
   - Não implementar todas as etapas de uma vez.
   - Desenvolver etapa por etapa e aguardar autorização do usuário antes de avançar.
   - Após cada alteração, explicar em exatamente duas linhas o que foi feito.
5. **Responsividade e Acessibilidade**:
   - Adaptação perfeita para computadores, notebooks e celulares.
   - Respeitar preferência do sistema operacional para redução de movimento (`prefers-reduced-motion`).
